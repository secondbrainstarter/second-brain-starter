# 06_Daily — Daily Notes

**Rule:** One daily note per day, filename = date (e.g. `2026-08-03.md`).

**Routine (17 minutes/day):**

- **Morning (7 min):** create your daily note → write down 3 goals → review
  yesterday's inbox.
- **Evening (10 min):** process the inbox → close your daily note
  (what went well / what did you learn / what matters tomorrow).

**Tip:** With Obsidian's Templates core plugin you can create notes with one
click: Settings → Core plugins → enable *Templates* → choose folder
`07_Templates`. Then: new note → insert template `Daily-Note` (or `Tagesnote`).

# 06_Daily — Tagesnotizen

**Regel:** Eine Tagesnote pro Tag, Dateiname = Datum (z.B. `2026-08-03.md`).

**Routine (17 Minuten/Tag):**

- **Morgens (7 Min):** Tagesnote anlegen → 3 Ziele notieren → Inbox von
  gestern durchsehen.
- **Abends (10 Min):** Inbox verarbeiten → Tagesnote abschließen
  (gut war / gelernt / morgen wichtig).

**Tipp:** Mit dem Templates-Kernplugin von Obsidian geht das Anlegen per
Klick: Einstellungen → Kern-Plugins → *Vorlagen* aktivieren → Ordner
`07_Templates` wählen. Dann: neue Notiz → Vorlage `Tagesnote` einfügen.
