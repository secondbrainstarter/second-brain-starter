# 07_Templates — Templates

**6 templates to start — 3 English, 3 German.** How to use them:

1. Open a template → copy the content → create a new note → paste.
2. Replace the placeholders (`{{title}}` = note name, `{{date}}` = today's date).
3. With the Templates core plugin it's easier: Settings → Core plugins →
   *Templates* → choose folder `07_Templates` → new note → insert template
   (replaces `{{date}}` automatically).

| Template (EN)   | When?                                        |
|-----------------|----------------------------------------------|
| `Daily-Note`    | Every day — 3 goals, focus, journal          |
| `Project-Note`  | Everything with a goal & an end date         |
| `Permanent-Note`| Ideas & insights that should stay            |

| Vorlage (DE)    | Wann?                                        |
|-----------------|----------------------------------------------|
| `Tagesnote`     | Jeden Tag — 3 Ziele, Fokus, Journal          |
| `Projektnote`   | Alles mit einem Ziel & Enddatum              |
| `Permanentnote` | Ideen & Erkenntnisse, die bleiben sollen     |

> **Note:** The full version (Second Brain Starter) contains 14 templates —
> including weekly review, meeting, goal, habit, book, decision & more.

# 07_Templates — Vorlagen

**6 Vorlagen für den Start — 3 Englisch, 3 Deutsch.** So nutzt du sie:

1. Vorlage öffnen → Inhalt kopieren → neue Notiz erstellen → einfügen.
2. Platzhalter ersetzen (`{{title}}` = Notizname, `{{date}}` = heutiges Datum).
3. Mit dem Templates-Kernplugin geht das bequemer: Einstellungen →
   Kern-Plugins → *Vorlagen* → Ordner `07_Templates` wählen → neue Notiz →
   Vorlage einfügen (ersetzt `{{date}}` automatisch).

| Vorlage         | Wann?                                        |
|-----------------|----------------------------------------------|
| `Tagesnote`     | Jeden Tag — 3 Ziele, Fokus, Journal          |
| `Projektnote`   | Alles mit einem Ziel & Enddatum              |
| `Permanentnote` | Ideen & Erkenntnisse, die bleiben sollen     |

|-----------------|----------------------------------------------|
| `Daily-Note`    | Every day — 3 goals, focus, journal          |
| `Project-Note`  | Everything with a goal & an end date         |
| `Permanent-Note`| Ideas & insights that should stay            |
