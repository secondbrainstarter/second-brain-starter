# 07_Templates — Vorlagen

**3 Vorlagen** für den Start. So nutzt du sie:

1. Vorlage öffnen → Inhalt kopieren → neue Notiz erstellen → einfügen.
2. Platzhalter ersetzen (`{{title}}` = Notizname, `{{date}}` = heutiges Datum).
3. Mit dem Templates-Kernplugin geht das bequemer: Einstellungen →
   Kern-Plugins → *Vorlagen* → Ordner `07_Templates` wählen → neue Notiz →
   Vorlage einfügen (ersetzt `{{date}}` automatisch).

| Vorlage | Wann? |
|---------|-------|
| `Tagesnote` | Jeden Tag — 3 Ziele, Fokus, Journal |
| `Projektnote` | Alles mit einem Ziel & Enddatum |
| `Permanentnote` | Ideen & Erkenntnisse, die bleiben sollen |

> **Hinweis:** Die Vollversion (Second Brain Starter) enthält 14 Vorlagen —
> auch Wochenrückblick, Meeting, Ziel, Habit, Buch, Entscheidung u.v.m.
