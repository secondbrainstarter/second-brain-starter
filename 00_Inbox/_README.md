# 00_Inbox — Eingangskorb

**Regel:** Alles landet hier — Ideen, Aufgaben, Gedanken, Links, Zettel.
Nicht sortieren, nicht entscheiden. Nur rein.

**Abends (5 Min):** Jede Notiz verarbeiten:

1. **Ist es eine Aufgabe?** → in dein Aufgaben-Tool oder in eine Projektnote.
2. **Ist es eine Idee?** → eigene Notiz mit eigenem Titel (eine Notiz = eine Idee).
3. **Braucht es eine Antwort/Recherche?** → als Aufgabe formulieren.
4. **Ist es erledigt/veraltet?** → löschen (oder in eine Projektnote packen).
5. **Leeren!** Die Inbox ist KEIN Archiv — sie ist ein Durchlauferhitzer.
